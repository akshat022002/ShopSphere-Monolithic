## Tech Stack

### Backend
- **Java 21**
- **Spring Boot 4.0.7**
- **Spring MVC** — REST API development
- **Spring Data JPA / Hibernate** — Database access and ORM
- **Spring Security** — Authentication and authorization
- **Spring Validation** — Request and data validation
- **Spring AOP** — Aspect-oriented programming

### Database & Caching
- **PostgreSQL** — Relational database
- **Redis** — Caching and data storage
- **Spring Cache** — Caching abstraction

### Authentication & Security
- **JWT (JSON Web Tokens)** — Token-based authentication
- **OAuth 2.0 Client** — OAuth-based login and authorization flows

### Integrations & External Services
- **Google Gemini via Spring AI** — Generative AI integration
- **Cloudinary** — Image and media management
- **Razorpay** — Payment gateway integration
- **Spring Mail** — Email functionality

### API Documentation
- **Springdoc OpenAPI / Swagger UI** — API documentation

### Mapping & HTTP Client
- **MapStruct** — Object mapping between DTOs and entities
- **OkHttp** — HTTP client

### Development & Testing
- **Maven** — Build and dependency management
- **Spring Boot DevTools** — Development-time utilities
- **Spring Security Test** — Security testing
